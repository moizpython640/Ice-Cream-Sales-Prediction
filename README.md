# Ice Cream Sales Prediction 🍦

A machine learning regression project that predicts ice cream sales using factors such as temperature and historical sales data.

## 📌 Project Overview

This project uses Linear Regression to analyze the relationship between temperature and ice cream sales and make predictions from the data.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## 🤖 Machine Learning Model

- Linear Regression

## 🎯 Goal

The goal of this project is to practice machine learning regression and understand how data can be used to predict future sales.

## 👨‍💻 Project Type

Machine Learning — Regression
